# 빌리 v3 배포 화면 패키지

- `svg/`: 앱 화면별 SVG 27개, 원본 지역·물품 사진 2개, 감탄이 상태 이미지 4개. 앱 화면은 투명 배경 프레임이므로 기존 발표 자료에 바로 배치하거나 Figma로 드래그할 수 있습니다.
- `Billy_v3_App_Screens.pdf`: 1440×810, 11페이지. 앱 화면 27개와 원본 사진·상태 이미지를 흐름별로 모았으며 화면을 클릭하면 배포 사이트로 이동합니다.
- `phone-png/`: 프레임을 포함한 고해상도 투명 PNG. SVG 가져오기가 제한되는 편집기에서 사용할 수 있습니다.
- `screens/`: 배포 사이트의 390×844 원본 캡처, 3배 해상도.
- `manifest.json`: 화면별 제목, 주소, 캡처 시각.
- `regional/`: 배포 사이트의 성북구 대여소 지도를 벡터 SVG로 저장했습니다. 캠퍼스 6곳 상세는 앱 프레임으로 각각 제공됩니다.
- `reference-assets/`: 원본 PDF의 돈암시장·센터 물품 사진, 감탄이 네 가지 상태 이미지. 사진 출처·이용 조건은 PDF 10쪽과 `reference-assets.json`을 참고하세요.

SVG는 실제 사이트 캡처 PNG를 포함하고 프레임만 벡터입니다. 웹 UI의 개별 텍스트·버튼을 편집할 수 있는 벡터 원본은 아닙니다. SVG 링크는 브라우저에서 동작하며 Figma로 가져오면 링크가 보존되지 않을 수 있으므로 바로 이동은 PDF 링크를 사용하세요. 로그인 후 해당 페이지로 진입할 수 있습니다. 통화의 순간 상태는 시연을 재생하며 다시 진행해야 합니다.

통화 화면은 배포 제품의 `?demo=script` 흐름을 캡처했습니다. 시연 표시를 지우거나 실제 예약 장면으로 꾸미지 않았으며 게시·예약 데이터는 수정하지 않았습니다. 감탄이 상태는 원래의 영어 표기와 위치를 유지했습니다. ‘AI가 신청서를 작성 중이에요’ 문장은 제거된 배포본입니다.

원본 `Seongbuk_Billy_v3.pdf`는 변경하지 않았습니다.
