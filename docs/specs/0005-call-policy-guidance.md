## 1. 문제와 목표

전화(통화 화면 `/rental`)로 물품을 빌리며 사용자가 빌리는 상황(여행, 이사, 아픔, 취미 모임 등)을 말하면, 신청완료 화면에서 그 상황과 관련된 센터 정책을 안내한다.

- 통화 중: 사용자 발화가 쌓일 때마다 백그라운드에서 관련 정책을 찾는다. **통화 화면에는 아무것도 표시하지 않는다.**
- 신청완료(바텀시트 `done` 단계): 정책 1개 = 가로로 긴 카드 1개. 카드를 누르면 센터 탭의 해당 상세 화면으로 이동한다.
- 상황을 말하지 않았거나, 말했지만 맞는 정책이 없거나, 매칭이 실패하면 **무작위 정책 1개**를 같은 카드 형식으로 추천한다(사용자 결정). 화면 흐름은 모든 경우에 같고 제목 문구만 다르다.

제외: 통화 중 에이전트의 정책 발화(음성 프롬프트 `VOICE_RULES` 변경 없음), 정책 신청 연동, 매칭 결과 저장, `/rental/classic` 구 화면.

## 5. API 계약 (`/api/v1`, 기존 envelope·세션·CSRF)

### `POST /policy-matches` → 200

상태를 바꾸지 않는 계산이라 `mutation`(멱등 저장)을 쓰지 않는다. 전역 훅 규칙대로 `Origin`, `X-CSRF-Token`, `Idempotency-Key` 헤더는 필요하다. 같은 본문 재요청은 새로 계산한다. 라우트 한도는 **세션당** 분당 30회다(Caddy 뒤에서는 모든 사용자가 같은 IP라 IP 기준이면 서로의 한도를 소모한다. 세션 토큰의 SHA-256을 키로 쓰고 세션이 없으면 IP).

```json
{ "utterances": ["다음 주에 친구들이랑 제주도 여행 가는데 캐리어 빌릴 수 있을까요?"] }
```

- `utterances`: 사용자 발화 1~30개, 각 1~500자(앞뒤 공백 제거). 웹은 30개를 넘으면 상황이 주로 나오는 처음 10개와 최근 20개를 보낸다.

```json
{
  "data": { "situation": "여행 준비", "policyIds": ["rental-guide", "club"] },
  "meta": { "…": "…" }
}
```

- `situation`: 발화에서 확인한 상황 요약(30자 이하) 또는 `null`.
- `policyIds`: 관련 정책 ID 0~3개, 중복 없음, 관련도 순. `rental-guide | mind-check | gotgan | club | membership`.

오류: 401 `SESSION_EXPIRED`, 403 `CSRF_REJECTED`, 422 `VALIDATION_ERROR`(빈 배열·길이 초과·추가 필드), 429 `RATE_LIMITED`, 503 `AI_UNAVAILABLE`(모델 실패·시간 초과·출력 검증 실패, 재시도 가능).

모드: `AI_MODE=live`는 `OPENAI_DECISION_MODEL`로 구조화 출력(정책 ID enum)을 받고 `OPENAI_DECISION_TIMEOUT_MS` 안에서 최대 3회 시도한다. `AI_MODE=fixture`는 계약 패키지의 키워드 매처 `matchPoliciesByKeyword`를 쓴다(시연 스크립트와 같은 규칙).

## 6. 상태·동시성·실패

- 호출 시점: 통화 중(그리고 승인 직후 통화가 끝난 뒤에도) 사용자 발화 목록이 1.2초 동안 바뀌지 않으면 그 목록 전체로 1회 호출한다. 발화가 바뀌면 진행 중인 응답은 버리고 마지막 목록의 응답만 채택한다. 새 통화 시작 시 초기화한다.
- 마지막으로 **받은** 응답은 새 검색이 진행 중이거나 실패해도(429·AI 시간 초과·503·네트워크) 유지한다. 그래서 첫 발화에서 찾은 상황이 이후 요청 실패로 사라지지 않는다. 새 응답이 오면 그것이 이전 응답을 대체한다(전체 발화를 다시 본 결과이므로 정책이 없다는 응답도 대체).
- 완료 화면 표시 규칙:
  - 이번 통화에서 받은 응답이 아직 없고 검색이 진행 중이면 "맞춤 정책을 찾고 있어요" 자리 표시 후 결과를 그린다(최대 지연은 서버 시간 제한).
  - 유지 중인 응답의 `policyIds`가 1개 이상이면 그 정책 카드(최대 3개), 제목 "말씀하신 상황에 맞는 정책이에요".
  - 그 밖의 경우(상황 미언급, 상황은 있으나 맞는 정책 없음, 받은 응답 없이 실패, 발화 없음)는 무작위 정책 1개, 제목 "이런 정책도 있어요". 무작위 선택은 통화마다 한 번만 하고 다시 그려도 바뀌지 않는다.
- 시연 스크립트(`/rental?demo=script`)는 서버를 부르지 않고 같은 키워드 매처를 브라우저에서 실행한다.
- 권한: 로그인 세션만 가능. 결과는 공개 센터 안내이므로 다른 사용자 데이터 노출 없음. 발화 안의 지시는 무시하도록 프롬프트에 명시하고, 출력은 enum·길이 검증 후 반환한다.
