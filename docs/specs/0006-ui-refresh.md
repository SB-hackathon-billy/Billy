## 1. 변경 내용

성북구 주민 전체(연령·성별 무관)가 화면마다 할 일을 바로 알아보도록 시각 위계를 정리한다.

- 배경: 상단 왼쪽 연두 빛 번짐 → 중립 바탕 그라데이션(`--gradient-page`, `body::before` 고정 레이어).
- 공용 토큰 추가: `--radius-{sm,md,lg,pill}`, `--shadow-{soft,raised,primary}`, `--color-glass`.
- 컴포넌트: 버튼은 알약형·최소 높이 54px(주요 버튼은 연두+그림자, 보조는 흰 바탕+얇은 테두리), 카드는 테두리 없이 흰 면+부드러운 그림자, 입력 52px, 하단 탭은 떠 있는 유리 막대, 상태 배지·필터·세그먼트는 알약형.
- 구분선·점선 상자·왼쪽 강조선을 여백과 글자 위계로 대체(요청·예약·물품 목록, 알림, 진행 기록, 예약된 기간, 결제 합계, 오류 안내).
- 중복·장식 문구 제거: 탭 이름과 겹치는 머리 라벨(둘러보기·물품 상세·알림·빌려주기·내 정보·센터 각 화면), 요청함·홈·입장 화면의 표어, 홈 소개 문단, 센터 카드 제목의 ↗, 사업 필터 번호. 검색 칸의 보이는 라벨은 숨김 처리(접근 이름 유지).
- 홈: 인사(작게) → 질문(큰 제목) → 통화 요청 카드 하나를 주요 행동으로, 카드 안 진한 알약 버튼 「말하거나 글로 요청하기」. 둘러보기는 보조 행.
- 내 정보: 카드 두 개 → 아이디 카드 하나 + 「내 요청 내역 보기」 주요 버튼 + 아이디 전환 보조 영역.
- 데모·실제 결제 없음 안내 문구는 유지하고 작은 보조 글씨로 표시.

제외: 라우팅·데이터·상태·핸들러·aria 이름, `/rental` 통화 화면(`voice-call/*`), 1번 해시 파일.

1번 파일(`scripts/module-1-baseline.json`)과 `features/voice-call/*`는 수정하지 않았다. `app.css`의 접수 화면 전용 규칙(`.voice-page`, `.call-*`, `.chat-message`, `.transcript`, `.voice-orbit`, `.voice-controls`)은 그대로 옮겼다. 공용 클래스(`.button`, `.content-card`, 입력, `.eyebrow` 등)의 모양만 바뀌어 `/rental/classic`과 통화 화면의 버튼 외형이 함께 바뀐다. 동작·문구·접근 이름은 같다.
