# 센터 기능·성북 색상 리서치

확인일: 2026-10-31 (Asia/Seoul). 공개 페이지를 직접 열람했다. 로그인, 회원가입, 신청, 게시글 작성은 수행하지 않았다. 아래에서 **관찰**은 사이트에 표시된 사실, **설계 제안**은 이번 MVP에 맞춘 판단, **미확인**은 공개 페이지만으로 알 수 없는 부분이다.

### 범위와 정책에 영향을 주는 관찰

- 공개 물품 대여 안내에 정회원 자격, 기간·운영일 제한, 센터 승인, 수령·반납 사진 제출이 명시되어 있다. 이 자료를 근거로 사용자에게 제외된 수령·반납·사진 판정·관리자 기능을 다시 넣지 않는다. 공공 데모 신청의 운영 규칙은 별도 데모 규칙으로 표시하고, 실제 기관 정책이 확정된 것처럼 표현하지 않는다. [물품 대여](https://sb1in.or.kr/online/rental)
- 물품 목록에서 청소기·사다리·프로젝터·캐리어 등 생활 물품과 대여 불가 상태를 확인했다. 데모는 대표 품목을 참고해 독립적인 ID·가용 일정·가격을 만들어야 한다. 공개 보유 수량이 특정 날짜의 가용 수량을 뜻한다고 간주하지 않는다. [물품 대여](https://sb1in.or.kr/online/rental)
- 이용안내의 회원 등급 설명보다 공간 상세 안내의 이용 대상이 좁다. 인증 연동 없이 실제 이용 자격을 판정할 수 없으며, 데모 자격 플래그를 실제 정회원 인증으로 표시하면 안 된다. [이용안내](https://sb1in.or.kr/about/guide), [공간 예약](https://sb1in.or.kr/online/space)
- 공간 예약 안내에는 무료 이용과 승인·출입 권한 절차가 있다. 기획서의 유료 공유대여 구상은 물품 대여에 적용하며, 기존 공간·프로그램 화면에 유료 정책을 임의로 확장하지 않는다. [공간 예약](https://sb1in.or.kr/online/space)
- 동아리·공지 목록이 비어 있는 경우를 관찰했다. 빈 화면뿐 아니라 예시 카드가 있는 화면을 별도 fixture로 준비하면 모바일 목록·상세를 검토할 수 있다. 현재 공개 콘텐츠 수는 고정 운영 데이터가 아니다. [동아리](https://sb1in.or.kr/online/club), [공지](https://sb1in.or.kr/news?cat=notice)
- 마이페이지·협력기관 내부, 실제 API, SSO 제공 여부, 센터의 재사용 허용 범위·연동 계약은 미확인이다. 기존 인프라 활용은 장기 연동 방향이며, 이번 데모에서 연결 완료라고 주장하지 않는다.

## 2. 대표 두 색 계열 선정

**권고: 네이비·그린.** 성북구 공식 CI는 성북 청색과 성북 녹색을 명시한다. 청색은 성북천·청렴, 녹색은 자연경관·희망을 뜻한다. 공식 별색은 각각 PANTONE 533EC, PANTONE 390EC이며, 인쇄용 값은 청색 C95 M72 Y15 K67, 녹색 C31 M0 Y100 K3이다. 이 근거로 사용자가 기억한 두 조합 가운데 네이비·그린을 선택한다. 노란색을 두 번째 대표 계열로 채택할 근거는 확인하지 못했다. [성북구 휘장 CI](https://www.sb.go.kr/www/contents.do?key=5967)

도시 BI 페이지에도 짙은 파랑과 그린 계열이 사용되지만, 일부 표기의 색 이름과 CMYK 조합이 직관적으로 맞지 않아 자체 팔레트의 수치 산출 근거로 삼지 않는다. CI의 명시적 두 계열을 우선한다. [성북구 도시 BI](https://sb.go.kr/www/contents.do?key=5979)

위 공식 값은 **출처 확인용**이다. 아래 화면용 HEX는 CMYK의 기계 변환값이나 공식 지정색이 아니라 새 디자인을 위한 제안이다. 공식 휘장 형태를 수채화로 변형하지 않고, 자체 물품·이웃·에이전트 모티프를 만든다.

| 토큰 | 자체 HEX | 용도 |
| --- | --- | --- |
| `color.ink` / `color.navy.800` | `#253C52` | 본문, 제목, 주요 CTA |
| `color.navy.400` | `#648196` | 장식 선·수채화 중간 농도. 작은 본문에는 사용 금지 |
| `color.navy.100` | `#E4EBF0` | 듣는 중·조회 중의 부드러운 배경 |
| `color.green.700` | `#42705B` | 승인 동작, 확정된 응답 표식 |
| `color.green.300` | `#91AD95` | 잎·물감 번짐·보조 일러스트 |
| `color.green.100` | `#E5EEE4` | 조율 카드·상태 배경 |
| `color.paper` | `#F8F7F1` | 따뜻한 종이색 화면 바탕 |
| `color.surface` | `#FFFFFF` | 정보 카드·입력 필드 |

직접 계산한 불투명 단색 기준 대비는 잉크/종이 10.59:1, 흰색/네이비 11.37:1, 흰색/그린 5.68:1이다. 중간 파랑/종이는 3.82:1이므로 작은 본문용으로 쓰지 않는다. 수채화 텍스처·투명도·이미지가 겹치는 최종 화면은 별도로 확인해야 한다. 색상 외에도 아이콘·문구로 상태를 구분한다.

## 3. 자체 에셋과 에이전트 시각 표현 제안

이 절은 제작 가이드이며, 이번 문서 작업에서 최종 이미지나 앱을 구현한 것은 아니다.

| 에셋 | 표현 | 권장 형식·규칙 |
| --- | --- | --- |
| 에이전트 중심 모티프 | 두 개의 잉크 방울이 번지고 연결되는 원형 | SVG 경로+CSS. 듣기·생각·전달·대기 상태는 실제 이벤트와 연결 |
| 공유대여 홈 그림 | 사다리·프로젝터·캐리어 주변의 작은 이웃 손길 | 독창적 수채화 비트맵 생성 또는 직접 일러스트, WebP/AVIF로 제공 |
| 물품 분류 그림 | 공구·청소·여행·취미 물품의 불균일한 채색 | 4종 이상 자체 SVG/일러스트. 실제 상품의 정확한 사진으로 오인하지 않게 표시 |
| 요청함 삽화 | 봉투·연결된 카드·물감 선 | 빈 상태·승인 대기·응답 도착용. 상태 설명을 대체하지 않음 |
| 종이/번짐 질감 | 낮은 대비의 가장자리 번짐 | 텍스트 뒤에는 피하고 장식 영역에 제한. 작은 반복 텍스처 사용 |

공통 버튼·시트·날짜 입력은 접근 가능한 컴포넌트를 기반으로 하되, 카드 비례·모서리·아이콘·배경·에이전트 표현을 자체 토큰으로 구성한다. 생성형 이미지 도구는 구현 단계의 선택지이며, 툴을 하나로 제한하지 않는다. 에셋 납품에는 출처·제작 방식·라이선스·대체 텍스트·장식 여부·용량 정보를 함께 둔다.

음성 상태와 업무 상태는 분리한다. 마이크가 꺼져도 `소유자 응답 기다리는 중`은 유지할 수 있고, 소유자가 실제로 누르기 전에는 승인 애니메이션을 재생하지 않는다. 조회 중에는 서버 작업 단계, 대기 중에는 마지막 갱신 시각과 다음 행동을 표시한다. 움직임 줄이기 설정에서는 정적인 상태 아이콘과 문구를 사용한다.

## 4. 확인 방법과 남은 사항

메뉴와 공개 안내는 브라우징 도구로 직접 열었다. 성북 CI 페이지는 일부 재조회에서 timeout이 있었으나 `www.sb.go.kr` 페이지를 열고, 동일 URL의 HTML을 직접 받아 두 별색·CMYK 텍스트를 재확인했다. 화면 내부의 신청 완료 동작은 실행하지 않았다.

센터 협의가 필요한 사항은 실제 인증·자격·운영 캘린더·공공 요금·시설 이용·연동 API다. 디자인 검토 사항은 자체 팔레트와 에이전트 모티프의 최종 선택이다. 이 미확인 사항을 데모 제작의 전제인 것처럼 숨기거나, 미정 기능을 MVP 필수로 추가하지 않는다.
