현재 MVP의 구현 경계

대여 흐름 · 데모 아이디, 상담형 음성, 요청·응답·조건 변경, 비교·선택과 실시간 갱신이 구현되어 있습니다.

안내·미리보기 · 결제 화면과 센터 신청·예약 양식은 미리보기입니다. 실제 결제·접수·예약은 이루어지지 않습니다.

검증 경계 · 실제 휴대폰·사람 음성·스크린리더 일부 검증은 남아 있습니다. 이 문서는 현재 구현 구조를 나타냅니다.

구현 근거와 화면 ID 읽는 법

E01·H01·R01–R06·O01·C01–C06·M01은 PRD의 16개 기준 ID입니다. 요청함의 ‘빌리기’, 센터 허브, 양식 같은 보조 영역에는 새로운 공식 ID를 부여하지 않았습니다. 서로 다른 화면이 같은 URL을 쓸 수 있고, 하나의 ID가 여러 URL에 대응할 수도 있습니다.
